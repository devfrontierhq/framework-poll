# Manual Testing Checklist

## 一、公開功能（不需 Admin）

### 投票流程

1. 點擊版塊卡片任意位置 → 應跳出「新增」dialog，有名字輸入框
2. 輸入名字 → 確認 → 圓點出現在剛才點擊的位置，toast 顯示成功
3. Hover 圓點 → 應顯示剛才輸入的名字
4. 留空名字 → 確認按鈕應該是 disabled，無法送出

### 觸控長按（平板 / 手機）

1. 以觸控裝置（或 DevTools 模擬）長按圓點 500ms → tooltip 顯示該圓點的名稱
2. 長按後放開 → tooltip 消失，且不跳出「新增」dialog
3. 長按放開後，點選版塊卡片空白處 → 應正常跳出「新增」dialog
4. 長按期間移動手指超過 10px → tooltip 不出現，視為捲動手勢

### 初始空狀態

1. 清空 IndexedDB（DevTools → Application → Storage → Clear Site Data）→ 重整頁面
2. 應出現「尚無版塊」空狀態 + 「建立預設框架板塊」按鈕
3. 點擊按鈕 → 建立 React（藍）、Vue（綠）、Angular（紅）三個版塊
4. 按鈕期間應顯示「建立中...」，之後版塊出現

## 二、管理員模式

### 解鎖 / 鎖定

1. 點擊「管理模式」 → 出現密碼輸入 dialog
2. 輸入錯誤密鑰 → 確認 → toast「密碼錯誤，請重試」，dialog 保持開啟
3. 輸入正確密鑰 → 確認 → 頂部出現黃色管理列，按鈕變成「匯出 CSV」+ 「新增版塊」
4. 點擊「退出」 → 黃色列消失，回到一般模式

### 新增版塊（解鎖後，無需再輸密鑰）

1. 點「新增版塊」→ 填寫名稱 + 選色 → 確認
2. 新卡片應出現在 Grid 中，帶入選定顏色

### 編輯版塊（解鎖後，無需再輸密鑰）

1. Hover 版塊卡片標題區 → 出現編輯 / 刪除按鈕
2. 點編輯 → dialog 預填現有標題和顏色
3. 修改 → 確認 → 卡片立即更新

### 刪除版塊（需再次輸入密鑰）

1. 點刪除 → 出現刪除確認 + 密鑰輸入 dialog
2. 輸入錯誤密鑰 → toast「刪除失敗」，版塊保留
3. 輸入正確密鑰 → 版塊消失，連帶所有圓點也消失

### 刪除圓點（需再次輸入密鑰）

1. 在 Admin 模式下，點擊任一圓點 → 出現刪除確認 + 密鑰輸入 dialog
2. 正確密鑰 → 圓點消失，版塊計數遞減
3. 錯誤密鑰 → 圓點保留
4. Admin 模式下，以觸控裝置長按圓點 500ms → 顯示 tooltip（行為同非 admin 模式）
5. 長按放開後，確認新增圓點與刪除圓點功能仍可正常操作

### 版塊計數

- Admin 模式下，版塊標題應顯示「React - 3」格式
- 新增圓點 → 計數 +1；刪除圓點 → 計數 -1
- 退出 Admin 模式 → 計數消失

## 三、CSV 匯出

1. Admin 模式下點「匯出 CSV」→ 按鈕顯示「匯出中...」→ 自動下載檔案
2. 驗證 CSV 內容：
   - 欄位：版塊名稱、項目名稱、建立日期、刪除日期
   - 用 Excel 開啟應正確顯示中文（UTF-8 BOM）
   - 日期格式：2026-03-17 14:30
   - 已刪除的圓點仍出現，刪除日期欄位有值
   - 未刪除的圓點，刪除日期欄位為空

## 四、邊界情況

- 相同名字的圓點：在同一版塊加兩個同名圓點，兩個都應成功建立（系統允許重複名稱）
- 圓點重疊：多次點擊同一位置，每個圓點應半透明（opacity 0.8）並帶白色邊框
- 空版塊名稱：新增版塊時留空標題，確認按鈕應為 disabled，無法送出
- 資料持久化：新增資料後重整頁面，所有資料應保留
- 有版塊時的空狀態按鈕：刪除所有版塊後重整，空狀態應再次出現，可再次初始化預設版塊
