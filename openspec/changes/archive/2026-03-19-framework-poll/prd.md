# 網頁版計分板 (Web Scoreboard) 開發規格書 v1.1

## 1. 專案概述

本專案為一個互動式計分系統，使用者可自定義多個「版塊（Category）」，並在各版塊下新增代表分數的「圓點」。系統需具備管理員模式鎖定、數據持久化儲存、以及自動化的排版與計數功能。

## 2. 核心功能規格

### A. 版塊管理 (Category Management)

- **新增版塊**：管理員模式下，點擊「+」按鈕，輸入標題後建立。
- **自動計數**：每個版塊頂部或顯眼位置需自動顯示該版塊內的圓點總數（例如：React - 12）。
- **顏色統一設定**：可針對個別版塊設定圓點顏色，該版塊內所有圓點顏色需保持一致。
- **自動排版**：採用響應式設計（Responsive Design），系統需根據螢幕寬度自動調整每列顯示的版塊數量（例如：桌機 4 欄、平板 2 欄、手機 1 欄）。
- **刪除功能**：
  - 管理員可刪除整個版塊。
  - 其版塊以軟性刪除設計。

### B. 計分與項目管理 (Scoring & Item Management)

#### 新增圓點

- 點擊版塊後，於下方輸入框輸入名稱並點擊「Add」，該版塊即增加一個圓點。
- 不需要驗證名稱是否重複。

#### 刪除單個圓點

- 點擊或右鍵點擊（視 UI 設計而定）已存在的圓點，跳窗提示是否確定刪除，並輸入管理員密鑰進行刪除。
- 刪除後，版塊的總數計分需同步更新。
- 刪除以軟性刪除設計。

#### 資訊顯示

滑鼠懸停於圓點上時，顯示該項目當初填寫的名稱。

### C. 安全與管理員模式 (Security & Admin)

#### 密鑰驗證 (Secret Key)

- **禁用法**：嚴禁將密鑰直接 Hardcode 在前端程式碼中。
- **實作方式**：密鑰需透過環境變數（.env）設定。
- **驗證邏輯**：前端接收使用者輸入後，與從環境變數讀取的正確值進行比對，通過後方可開啟編輯/刪除/設定功能。
- **功能權限**：非管理員模式下，使用者僅能瀏覽計分狀況、投點，無法進行任何修改。

### D. 資料儲存與匯出 (Storage & Export)

- **數據保存 (Persistence)**：使用 localStorage 或 IndexedDB 儲存所有版塊與計分資訊，確保瀏覽器重新整理或關閉後資料不會遺失。
- **CSV 匯出**：
  - 一鍵匯出功能。
  - CSV 格式應包含：版塊名稱, 項目名稱, 建立日期, 刪除日期。

## 3. 技術開發需求 (Technical Requirements)

- **前端框架**：建議使用 React / Vue / Angular（視開發團隊習慣）。
- **樣式處理**：建議使用 CSS Grid 或 Flexbox 實現自動流動排版（Auto-layout）。
- **環境變數**：編譯時需透過 Build Tool（如 Vite, Webpack）將 .env 中的密鑰注入。

## 4. 介面流程簡述 (UI Flow)

1. **瀏覽**：進入頁面，看見自動排版的版塊與各版塊計分總數。
2. **解鎖**：點擊管理按鈕 → 輸入密鑰 → 密鑰與 .env 值比對 → 進入管理模式。
3. **操作**：新增版塊 → 設定顏色 → 點擊版塊新增項目（圓點）→ 圓點數自動累加。
4. **維護**：可隨時刪除個別圓點或整個版塊。
5. **存檔**：所有變動即時存入本地瀏覽器儲存空間。
